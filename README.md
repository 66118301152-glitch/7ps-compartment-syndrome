# 7Ps Assessment - Compartment Syndrome

เว็บประเมิน 7Ps สำหรับใช้ประเมินภาวะ Compartment Syndrome  
พัฒนาเป็น static website ด้วย HTML, CSS, JavaScript  
ไม่มี backend และสามารถ deploy ด้วย GitHub Pages ได้

## คุณสมบัติ
- กรอกข้อมูลผู้ป่วย
- ประเมิน 7Ps
- ดูวิธีประเมินแต่ละ P
- สรุปผลอัตโนมัติ
- บันทึกข้อมูลไว้ใน browser ด้วย localStorage

## เทคโนโลยีที่ใช้
- HTML
- CSS
- JavaScript

## การใช้งาน
เปิดไฟล์ `index.html` หรือ deploy ผ่าน GitHub Pages
